Avery Johnson's Learning by crafting Homework Assignment

Homework Analyzer

Learning Goals:
1. Be able to write both for and while loops
2. Trace execution of loops
   
For the homework assignment you will be helping a teacher create an easy way to present data about their students grades:

These are the grades for Student X:
[83, 68, 93, 99, 77, 85]

Students need to:

calculate the highest score

calculate the average

calculate how many scores are passing(higher than 75)


Students can use for loops, while loops, or both
